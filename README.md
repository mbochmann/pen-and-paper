# Pen & Paper

Gemeinsame Abenteuer für **zwei Spieler und eine KI als Spielleitung**, auf Deutsch. Kein Vorwissen nötig.

## Unser erstes Abenteuer

**[AQUILA – Das Geheimnis der Morgenquelle](campaigns/001-aquila/README.md)**

Eine römisch geprägte Stadt bereitet ein Fest vor. Dann versiegt der große Brunnen. Zwei Gefährten geraten zwischen widersprüchliche Aussagen, alte Wasserwege und eine Entscheidung, die weit über das Fest hinausreicht.

- Einstieg: [Spielerunterlagen](campaigns/001-aquila/players/start.md).
- Figuren: [Sechs spielbereite Rollen](campaigns/001-aquila/players/characters.md).
- Regeln: [Aquila – Zwei Gefährten, Version 1](campaigns/001-aquila/players/rules.md).
- Stand: **Vor der Figurenwahl. Noch keine Handlung ausgespielt.** Der aktuelle Fortschritt steht immer im [Spielerjournal](campaigns/001-aquila/players/journal.md).
- Wiederaufnahme in einem beliebigen Chat mit Repository-Zugriff:

> Sei unser Spielleiter für mbochmann/pen-and-paper. Lies AGENTS.md, campaigns/index.json und den dort angegebenen Einstieg. Lade den aktuellen Spielstand von main, ohne Geheimnisse zu verraten. Setze an der gespeicherten Frage fort.

## Für die Spielleitung

[AGENTS.md](AGENTS.md) → [Datenstruktur](structure/README.md) → [Speicherprotokoll](structure/save-protocol.md) → [Kampagnenindex](campaigns/index.json).

Markdown erklärt die Welt und die Regeln. JSON enthält den verbindlichen Zustand. JSONL hält tatsächliche Entscheidungen fest. Git archiviert vollständige Speicherpunkte. Pläne und mögliche Ereignisse sind **kein** gespielter Kanon.

Die Ordner `gm/` und `state/` enthalten Spoiler. Die Trennung ist eine Lesehilfe, keine Zugriffssperre. Das Repository ist öffentlich; ausschließlich fiktive Figuren und neutrale Spielerplätze speichern, keine echten Namen, Geburtsdaten oder privaten Familienangaben.

Keine laufende Hintergrundsimulation: Die KI speichert während aktiver Spielzüge. Ohne Repository-Zugriff darf sie keinen erfolgreichen Savepoint behaupten. Kein Abonnement und kein zeitgesteuerter Dienst erforderlich.
